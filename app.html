의료기술직 모의고사 앱

앱을 열면 바로 오늘 문제가 나옵니다. 새 문제는 매일 오전 6시에 올라옵니다.

버튼이 안 되면 여기를 길게 눌러 '링크 다운로드'

설치 방법
  1. "앱 받기"를 누르면 medtech.apk가 저장됩니다. 화면 아래나 알림창의 파일을 누르세요.
  2. "출처를 알 수 없는 앱" 허용을 물으면 설정 → 허용을 켜고 돌아와 설치를 누르세요.
  3. "Play 프로텍트" 경고가 나오면 자세히 → 무시하고 설치를 누르세요. 직접 만든 앱이라 나오는 안내입니다.
  4. 홈 화면의 의료기술직 모의고사 아이콘을 누르고 이름을 한 번만 입력하면 됩니다.
아이폰은 앱 파일을 설치할 수 없습니다.
이 링크를 열고 아래 공유 버튼 → 홈 화면에 추가를 누르면 앱처럼 쓸 수 있습니다.
